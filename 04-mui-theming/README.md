# Phase 04 — MUI Theming & Design System

Không phải "biết dùng component MUI" mà "làm chủ hệ thống theme để scale cho cả team". Đây là Milestone 5 dự án.

## Các bài
1. `01-theme-structure` — Cấu trúc theme, override toàn cục
2. `02-component-customization` — sx vs styled vs theme.components
3. `03-dark-mode-css-vars` — Dark mode mượt bằng CSS variables
4. `04-design-tokens` — Tách token, brand theme thứ 2

## Mục tiêu cả phase
Thiết kế được theme mà dev mới chỉ cần dùng component, không viết CSS ad-hoc; đổi được brand/dark mode không nhấp nháy.

> MUI cập nhật nhanh (v6/v7 đổi nhiều về theming & CSS variables). Khi vào phase này, báo mình biết phiên bản MUI bạn dùng — mình sẽ tra Context7 lấy docs bản mới nhất cho từng API.
