# Phase 05 — Security & Maintainability / Operations

Phần senior để tâm nhất: quyết định app sống lâu và an toàn hay không. Đây là Milestone 6 dự án.

## Các bài
1. `01-xss-csp` — XSS và Content Security Policy
2. `02-auth-cors` — Auth an toàn, CORS, CSRF, cookie
3. `03-testing` — Unit / component / e2e
4. `04-observability-ci` — Error tracking, Web Vitals field, CI/CD

## Mục tiêu cả phase
Bạn review được PR của người khác và chỉ ra lỗ hổng bảo mật, code khó bảo trì, và vấn đề performance.
