# LEVEL 3 — Specializations & Breadth

> Level 1 (00–05): làm app tốt. Level 2 (06–11): kiến trúc & quy mô.
> Level 3 (12–17): **lấp kín các mảng còn thiếu** để thành frontend "full-spectrum" — CSS gốc, real-time/API/auth mở rộng, testing sâu, đồ hoạ/animation, mạng & phân phối thích ứng, và các chuyên biệt (WASM, local-first).

## Bản đồ Level 3

| Phase | Chủ đề | Lấp gap |
|-------|--------|---------|
| `12-css-layout-mastery` | Flexbox/Grid, container queries, `:has()`, cascade layers, kiến trúc CSS | ❗ CSS gốc bị bỏ qua ở Level 1 |
| `13-realtime-api-auth` | Socket.IO, SSE, WebRTC, GraphQL, OAuth2/OIDC, WebAuthn | Real-time & API & auth mở rộng |
| `14-testing-advanced` | Unit cơ chế, MSW, Playwright E2E, chiến lược test | Testing sâu |
| `15-animation-graphics` | Web Animations API, SVG, Canvas, image handling nâng cao | Đồ hoạ & animation craft |
| `16-network-adaptive` | HTTP/1.1·2·3, adaptive loading (mobile/PC), cross-tab, i18n workflow | Mạng & phân phối thích ứng |
| `17-specializations` | WebAssembly, Local-first & CRDT, product engineering | Chuyên biệt cao cấp |
| `18-pwa-app-extension` | PWA, offline strategy, build mobile app, browser extension | Đóng gói thành sản phẩm đa nền tảng |

## Nguyên tắc Level 3

- **Breadth có chủ đích.** Không cần master mọi phase — biết đủ để *chọn đúng công cụ* và *học sâu khi dự án cần*. Đây là "T-shaped" mở rộng thành "comb-shaped".
- **Mỗi phase là một chuyên môn có thể đào sâu riêng.** Coi đây là menu: khi dự án chạm tới (cần đồ hoạ, cần real-time, cần offline sync), lật đúng phase ra học kỹ.

## Thứ tự đề xuất

`12` (CSS) học sớm — nó là nền mọi UI. `14` (testing) học song song bất cứ lúc nào. `13`, `15`, `16`, `17` học **theo nhu cầu dự án** — không tuyến tính.
