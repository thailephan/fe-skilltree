# Phase 03 — Browser APIs chuyên sâu

Các API bạn muốn làm chủ. Học theo dự án: biến dashboard thành app offline-first, real-time. Đây là Milestone 3 & 4.

## Các bài
1. `01-indexeddb` — Lưu trữ dữ liệu lớn phía client
2. `02-service-worker` — Offline, caching strategies, PWA
3. `03-websocket` — Real-time, reconnect, heartbeat

## Mục tiêu cả phase
Chọn đúng công nghệ lưu trữ/giao tiếp cho từng bài toán và xử lý được các ca lỗi thực tế (mất mạng, reconnect, tab ẩn, dữ liệu cũ).
