# Phase 00 — JavaScript & Browser Foundations

Đây là phần bạn tự nhận "chưa đi sâu". Phải chắc chỗ này, nếu không mọi thứ phía sau đều lung lay.

## Các bài
1. `01-event-loop` — Event loop, macrotask vs microtask, rAF/rIC
2. `02-memory-closures` — Stack/heap, reference, closure & memory leak
3. `03-async-deep` — async/await dưới lớp đường, xử lý lỗi, Promise combinators
4. `04-debounce-throttle` — Tự viết debounce/throttle từ đầu

## Mục tiêu cả phase
Sau phase này bạn phải: vẽ được sơ đồ event loop, đoán đúng output code async bất kỳ, và biết nguồn gốc của memory leak phổ biến.
