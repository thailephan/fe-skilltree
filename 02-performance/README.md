# Phase 02 — Performance Optimization

Giờ bạn đã hiểu browser, phase này là áp dụng. Nguyên tắc bất di bất dịch: **đo → tìm bottleneck → sửa → đo lại**. Không đoán mò.

## Các bài
1. `01-web-vitals` — LCP, INP, CLS: nguyên nhân & cách chữa
2. `02-react-rerender` — Re-render thừa, memo/useMemo/useCallback, virtualization
3. `03-bundle-splitting` — Code splitting, lazy load, tree shaking, phân tích bundle
4. `04-web-workers` — Offload tính toán nặng khỏi main thread
5. `05-virtual-scroll-lazy-render` — Virtual scrolling hoạt động thế nào & lazy rendering

## Mục tiêu cả phase
Cầm một app chậm, bạn có quy trình chẩn đoán bài bản và đưa được Core Web Vitals về ngưỡng "tốt".
