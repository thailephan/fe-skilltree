# Phase 01 — How the Browser Works

Kiến thức tạo ra khác biệt lớn nhất giữa mid và senior. Hiểu browser render thế nào thì mọi tối ưu performance về sau đều tự nhiên.

## Các bài
1. `01-rendering-path` — Critical Rendering Path: DOM → CSSOM → Layout → Paint → Composite
2. `02-reflow-repaint` — Reflow vs Repaint vs Composite, cái nào đắt
3. `03-gpu-layers` — Layers, GPU compositing, `will-change`
4. `04-loading-strategies` — async/defer, preload/prefetch, render-blocking

## Mục tiêu cả phase
Nhìn một đoạn CSS/JS là biết nó gây layout, paint hay chỉ composite; biết resource nào chặn render và cách gỡ.
